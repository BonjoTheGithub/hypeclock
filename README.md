# HypeClock

Game release countdown website with a mobile-first UI, search, trailers, upcoming releases, and a FreeToGame-powered popular-games section.

The site is deployed with GitHub Pages. A scheduled GitHub Action refreshes the cached FreeToGame data every six hours so visitors do not need a local server or API key.

## Mobile

The interface includes responsive navigation, swipeable platform filters, a 2x2 countdown layout on phones, single-column game cards, full-width controls, and phone-friendly bottom-sheet modals.
